### 10/14 环境打通与接口适配

**1. 安装 uv（用户目录，无系统风险）**
- uv 0.13.0 → `/home/lab416/.local/bin/uv`（用官方脚本安装，未用有风险的 snap --classic）

**2. 克隆 openpi 官方仓库**

- 配置 `git config --global url."git@github.com:".insteadOf "https://github.com/"`，
  解决 uv sync 中 lerobot 依赖走 HTTPS 失败的问题

**3. uv sync 安装依赖**
- `GIT_LFS_SKIP_SMUDGE=1 uv sync` 成功，.venv 约 7.7GB / 509 个包
- 额外安装：`mujoco`、`mujoco-python-viewer`、`pyyaml`、`gsutil`

**4. 关键问题：模型配置名与下载损坏**
- ❌ `pi0_base` 在 openpi 中并非可推理的配置名（base 权重仅用于微调）
  → 改用 `pi0_droid`（DROID 桌面操作微调模型，支持 0-shot 推理，动作 8 维）
- ❌ 首次下载用 gcsfs 回退，产生**损坏的 checkpoint**
  （报 `OUT_OF_RANGE`，缓存目录出现嵌套 `pi0_droid/pi0_droid`）
  → 安装 gsutil 后重新下载（约 11 GB），下载中

**5. 脚本接口适配（run_pi0_grasp.py）**
- 观测改为 pi0_droid 规范：`exterior_image_1_left` + `wrist_image_left`(HWC uint8)
  + `joint_position` + `gripper_position` + `prompt`
- 渲染两路相机（全局 + 腕部）
- 动作按 8 维解析：xyz / 旋转 / 夹爪
- 实现 action chunk 队列下发（每次推理取 chunk 前 action_chunk_steps 步依次执行）
- 清理未使用导入/变量

**6. 配置更新（config.yaml）**
- `config_name: pi0_droid`，`action_dim: 8`
- 新增 `scene.wrist_camera: wrist_cam`、`scene.table_height: 0.4`
- `control.action_chunk_steps: 5`

**7. 无显示环境渲染验证 + 脚本健壮性**
- 用 EGL 离屏渲染验证通过：场景加载 (nv=20, nu=8, ncam=2) ✅
  、双相机渲染 (224×224 uint8) ✅、雅可比 IK 求解 ✅
- `run_pi0_grasp.py` 改进：无 `DISPLAY` 时自动设置 `MUJOCO_GL=egl`；
  `mujoco_viewer` 改为按需导入（`--no-viewer` 无需该依赖也行）
- 校验 openpi venv 运行依赖齐全：mujoco 2.3.7 / mujoco_viewer / yaml 6.0.2
  / numpy 1.26.4 / jax 0.5.3 / torch 2.7.1+cu126

**8. pi0_droid 权重下载完成 + 全链路跑通 ✅**

  - 策略加载 ✅、action chunk shape (10,8) ✅、双相机渲染 224×224 uint8 ✅
